Generador de reportes de consumo

Elegí la cuenta, anotá las recargas de saldo y obtené el reporte para el cliente. Los datos se leen en vivo de las bases.

1. Datos del reporte

El costo de una llamada es su precio menos ese porcentaje. En los mensajes el costo sale de la columna cost_usd de la base de WhatsApp, no se calcula.

Si dejás el período vacío se trae todo el historial de la cuenta.

2. Datos desde la base en vivo

Usa el período de arriba; vacío = todo el historial. Trae llamadas (CallLog), mensajes (ChatbotMessage) y las recargas cobradas en Whop (CreditPurchase) — todo valorado por lo que se le descontó del saldo.

4. Enviar por correo Gmail

Va el PDF del reporte adjunto (el mismo que ves abajo) y, si lo marcás, el Excel con las dos hojas. El correo del cliente queda guardado para esa cuenta.

Servidor local requerido

Esta herramienta lee las bases en vivo, así que hay que abrirla servida: cd server && node scripts/reporte-consumo-server.js y entrar por http://localhost:5055.
